# Mon Pokédex

Ouvre `index.html` dans un navigateur. 1025 slots ; clique sur un slot (ou « Ajouter une image »), dépose/colle l'image, choisis le Pokémon, ajuste tolérance/contour, Enregistre.
Le fond est détouré automatiquement avec un contour blanc façon sticker. Les images sont stockées dans le navigateur (IndexedDB) ; utilise « Sauvegarde » pour exporter un fichier.
